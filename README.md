# USA MercWork bug tracker

This is the public bug tracker for the Roblox game USA MercWork. It holds issues only; the game's code is not here.

Issues are filed by the triage bot or by developers from bug reports posted in Discord. If you've found a bug, please report it in the bug-report channel of the USA MercWork Discord server rather than opening an issue here. A dev or the triage bot will file it and link the issue back in your thread.

## Labels

| Label | Meaning |
|---|---|
| `triage` | New, not yet confirmed |
| `investigating` | Team is actively looking |
| `confirmed` | Reproduced or root-caused |
| `needs-info` | Waiting on the reporter |
| `not-code` | Asset, config or Roblox platform issue |
| `duplicate` | Same as an existing issue |
| `fixed-pending-release` | Fixed, waiting for the next game update |

Security issues and exploits are never tracked here. Report them privately to the devs in Discord.
